# About

An E-commerce page made for shopping of clothing materials.
Front-End Development: Built using React JS, featuring product display, product cart, and 
 login/registration pages.
Back-End Development: Developed with Express, Node.js, and MongoDB, creating APIs for adding, 
 displaying, and updating products, updating cart items, and user login/registration.
Admin Panel: Provides functionality to add and update products on the e-commerce website.
